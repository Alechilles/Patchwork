# Patchwork Wiki

Patchwork helps Hytale mod authors make small, compatible changes to existing JSON assets. Instead of copying an entire asset just to change one setting, you write a small patch that describes the change. Patchwork combines applicable patches into its own generated asset pack and leaves the original files alone.

You do not need programming experience to make a basic Patchwork definition. Start with one asset, one small change, and the guided Asset Editor fields.
